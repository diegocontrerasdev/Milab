##  About the Project

**MILAB** is an environmental monitoring system developed using ESP32, electronic sensors and Firebase Realtime Database. It collects environmental measurements and displays them through a web dashboard, allowing users to visualize current conditions and review historical records.

##  Purpose

The main purpose of MILAB is to use Internet of Things (IoT) technology to collect, store and visualize environmental data. The project aims to make environmental information easier to understand through real-time monitoring and organized data visualization.

##  How It Works

1. **Data Collection:** Sensors measure environmental variables such as temperature, humidity, light, gas levels and sound.
2. **Data Processing:** The ESP32 receives and processes the sensor readings.
3. **Cloud Storage:** Measurements are sent to Firebase Realtime Database.
4. **Data Visualization:** A web dashboard retrieves the information and displays it through indicators, cards and charts.
5. **Historical Records:** Previous measurements are stored to allow comparison and monitoring over time.
